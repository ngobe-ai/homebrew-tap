# ngobe Homebrew tap

Homebrew formulae for [ngobe](https://github.com/ngobe-ai/ngobe-cli), a coding agent for local models with live, official-source verification.

    brew install ngobe-ai/tap/ngobe

Update with `brew upgrade ngobe`.

`Formula/ngobe.rb` is generated and pushed by the release workflow in
[ngobe-ai/ngobe-cli](https://github.com/ngobe-ai/ngobe-cli/blob/main/.github/workflows/publish.yml)
from each release's `SHA256SUMS`. Don't edit it by hand.
